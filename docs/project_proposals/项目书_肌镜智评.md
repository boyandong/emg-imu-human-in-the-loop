# 一、项目摘要

力量训练中的“动作是否标准”与“肌肉是否正确发力”是两个相关但并不等价的问题。教练和摄像头能够观察人体外部姿态，但难以直接判断目标肌群是否充分激活、左右侧是否失衡、是否存在代偿发力；表面肌电（surface electromyography，sEMG）能够反映肌肉电活动，却缺少全身姿态和动作阶段信息。现有健身动作评估产品多以单摄像头姿态识别为主，科研级肌电平台则价格较高、操作专业、输出解释门槛高，两者之间仍存在产品与研究空白。

本项目拟研发一套融合**多视角短视频/人体姿态、sEMG及可选IMU**的健身动作质量评估系统。系统以短时完整动作视频而非孤立静态照片为主要视觉输入，提取关节关键点、动作阶段和姿态偏差；同步分析多通道sEMG，提取肌肉激活、左右平衡、协同与代偿相关特征；必要时引入IMU补充动作速度、角速度和稳定性信息。模型最终输出动作质量分数、错误类型、肌肉负荷/激活提示、动作阶段定位、置信度及可理解的纠正建议。

项目的核心研究问题不是“识别某个动作”，而是：

> 在受试者、拍摄视角、训练水平、负重、动作速度、肌电贴片位置及可用模态发生变化时，模型能否仍然稳定地评价动作质量？

为此，项目将团队已有的“重泛化”深度学习能力迁移到视觉—肌电多模态动作质量评估，重点开展跨个体泛化、跨视角鲁棒性、电极偏移鲁棒性、模态缺失鲁棒性和少量校准研究。学术阶段以FLEX等数据集开展算法验证；产品阶段自建小型、授权清晰的同步视频—sEMG数据，用于实时演示和竞赛验证。

第一阶段建议聚焦**深蹲**完成最小闭环，再扩展至杠铃划船和推举等动作。项目预期形成可复现实验代码、多模态泛化模型、动作评估原型软件、小型自建数据集、论文/专利或软件著作权材料，以及可用于创新创业竞赛的现场演示系统。

# 二、项目需求与问题定义

## 2.1 需求背景

世界卫生组织建议成年人每周至少进行两天覆盖主要肌群的力量训练；美国运动医学会于2026年更新力量训练指南，强调持续、可执行的训练比复杂方案更重要。[1][2] 随着力量训练进入家庭、普通健身房和移动端，训练者面临的主要问题已经不只是“有没有课程”，而是：

1. 无教练或教练无法持续陪同时，训练者不知道动作是否在全过程中保持稳定；
2. 视频或镜面只能看到外部姿态，无法验证目标肌群是否真正参与；
3. 相同外观动作可能对应不同的肌肉募集策略，单纯骨架角度容易漏掉代偿发力；
4. 初学者难以理解原始肌电曲线和复杂生物力学指标，需要可执行的语言反馈；
5. 多数算法在固定受试者、固定拍摄角度、固定场景中效果较好，换人、换角度或重新贴电极后性能容易下降；
6. 专业肌电与运动捕捉设备成本和操作门槛较高，难以直接进入普通健身训练。

因此，市场和研究需要一种介于“普通视频健身App”与“专业生物力学实验室”之间的解决方案：成本可控、结果可解释，并能在真实使用条件下保持稳定。

## 2.2 目标用户

### 核心用户

- 有一定力量训练需求、但无法长期获得一对一教练服务的初级和中级训练者；
- 健身房教练、体能训练师，用于提高多人训练评估效率；
- 高校体育教学、运动科学实验室，用于训练动作教学和研究。

### 拓展用户

- 运动康复机构及远程康复场景；
- 竞技体育训练团队；
- 需要动作与肌肉负荷分析的职业健康和人体工效学场景。

本项目第一阶段以健身训练为主，不直接进入医疗诊断和长期损伤预测。

## 2.3 典型使用场景

以深蹲为例，用户在训练前佩戴2—4个sEMG传感器，并使用手机或固定摄像头拍摄一次完整动作组。系统完成：

1. 自动识别每次重复及离心、最低点、向心、锁定等阶段；
2. 判断下蹲深度、躯干前倾、膝关节轨迹、左右偏移等外部动作问题；
3. 判断目标肌肉激活是否充分、左右激活是否失衡、是否出现异常代偿趋势；
4. 形成“动作外观 + 肌肉激活”的综合评分；
5. 给出可定位到具体阶段的提示，例如：“第4—6次起身阶段躯干前倾增加，同时腰背肌激活占比持续上升，建议降低重量并调整核心稳定。”

该输出属于**训练动作质量和肌肉激活模式提示**，不是临床伤病结论。

## 2.4 现有方法的主要缺口

| 现有方案 | 能解决的问题 | 主要缺口 |
|---|---|---|
| 人工教练观察 | 能结合经验给出动作建议 | 成本高、覆盖时间有限，难以量化内部肌肉激活 |
| 单摄像头/姿态识别App | 低成本识别关节角度、计数和明显错误 | 遮挡与视角敏感；看不到肌肉募集、左右激活和代偿 |
| 智能手表/IMU | 记录速度、重复次数、动作节奏 | 对复杂姿态错误与目标肌肉激活解释有限 |
| 专业sEMG系统 | 高质量记录肌肉电活动 | 设备与软件专业，解释依赖专家，跨人自动评估能力通常不是产品核心 |
| 本项目 | 融合外部运动学与内部肌电，并强化真实条件下泛化 | 仍需解决数据、同步、佩戴和标注等工程难题 |

# 三、项目拟解决的问题与建设内容

## 3.1 项目定位

本项目定位为：

> 面向健身训练的泛化型多模态动作质量评估系统，通过融合视觉姿态与表面肌电，回答“动作做得是否合理、肌肉用得是否合理、问题发生在哪个阶段”。

为了避免范围失控，项目不在第一阶段承诺：

- 替代专业教练；
- 诊断肌肉、骨骼或神经系统疾病；
- 根据一次训练预测未来是否受伤；
- 使用sEMG绝对值直接推算真实肌肉力量；
- 一开始覆盖所有健身动作和所有人群。

## 3.2 产品与研究的分层方案

### A. 学术研究版

- 输入：FLEX的5视角视频、3D姿态、sEMG及生理信息；
- 任务：动作质量回归、错误类型识别、跨被试与跨视角泛化；
- 重点：验证团队泛化模型是否能在多模态AQA任务上取得稳定提升；
- 输出：论文实验、消融研究、鲁棒性研究、可复现代码。

### B. 最小可行产品（MVP）

- 输入：单手机短视频 + 2—4通道sEMG；
- 动作：优先深蹲；
- 输出：重复计数、动作阶段、基础姿态错误、目标肌群激活、左右差异、综合评分及反馈；
- 目标：形成现场可演示的完整闭环。

### C. 专业增强版

- 输入：2—3个固定视角 + 4—8通道sEMG + 可选IMU；
- 动作：扩展至深蹲、杠铃划船、过顶推举等；
- 用户：健身房、教练团队、体育教学或研究机构；
- 特点：更稳定的多视角姿态、更完整的肌肉协同和动作动力学分析。

## 3.3 核心功能

1. **动作识别与重复分割**：识别动作类别、每次重复及动作阶段；
2. **视觉姿态评价**：输出关节角度、轨迹、稳定性和错误类型；
3. **肌电激活分析**：输出激活强度、激活时序、左右平衡和肌群协同特征；
4. **多模态综合评分**：融合姿态、肌电及可选IMU，输出连续质量分数与错误标签；
5. **泛化与轻校准**：降低换人、换视角、换负重、轻微电极偏移后的性能下降；
6. **模态缺失处理**：某个视角、部分sEMG通道或IMU缺失时仍能给出降级结果；
7. **可解释反馈**：指出“哪个阶段、哪个姿态或肌群、出现什么问题、建议如何调整”；
8. **数据与报告**：记录每次训练的分数、稳定性、左右差异和长期趋势。

## 3.4 建议首批动作

研究阶段建议选取以下三类常见力量训练动作：

| 动作 | 选择理由 | 主要视觉问题 | 主要肌电问题 |
|---|---|---|---|
| 深蹲 | 易展示、动作阶段明确、FLEX与Fitness-AQA均可支持 | 深度不足、躯干前倾、膝轨迹、左右偏移 | 大腿前后侧、臀肌、腰背肌参与与代偿 |
| 杠铃划船 | 上肢与躯干协同明显 | 躯干稳定、肩胛/肘轨迹、动作幅度 | 背部、肱二头肌、后三角与腰背参与 |
| 过顶推举 | 易出现耸肩、腰椎代偿 | 手臂轨迹、躯干后仰、左右不对称 | 三角肌、肱三头肌、斜方肌与核心代偿 |

MVP阶段只完成深蹲即可，另外两个动作作为扩展，不应同时拖慢首个闭环。

# 四、竞品与相关方案分析

## 4.1 竞品分层

项目并不存在一个完全同构的单一竞品。真正需要对比的是四类替代方案：纯视觉健身教练、专业EMG/运动捕捉系统、轻量肌电评估工具、智能肌电服，以及已发表的视觉+EMG工程原型。

## 4.2 代表性竞品/方案

| 代表方案 | 公开能力 | 主要优势 | 相对本项目的空白或差异 |
|---|---|---|---|
| Spottr等纯视觉健身App | 手机拍摄训练视频，姿态跟踪、动作评分、视频标注和反馈[3] | 使用门槛低、无需穿戴、易传播 | 公开能力以视觉为主，不能直接观察目标肌群激活；对视角、遮挡和外观相似但发力不同的情况存在天然限制 |
| AEKE等智能健身设备 | 摄像头捕捉骨骼点，实时纠错，结合课程、训练计划和硬件[4] | 产品闭环与课程生态较强 | 主要以运动学和设备数据为核心；本项目以视觉+sEMG及跨个体泛化形成差异 |
| Noraxon专业运动分析平台 | sEMG、IMU 3D运动捕捉、视频、力台和统一分析软件[5] | 数据质量高、设备模块完整、适合科研和临床/运动机构 | 成本、配置与使用门槛高；本项目不与其硬件精度正面竞争，而强调低成本自动评分、解释和泛化 |
| mDurance | 1024 Hz sEMG、惯性传感器、移动端/云端、肌肉活动和关节活动度评估[6] | 轻量、专业、具有移动端和云端能力 | 更偏专业肌肉评估与康复工具；本项目重点是健身动作质量、多模态自动融合和跨个体鲁棒性 |
| Myontec MShirt Plus | 16通道EMG与3个IMU，覆盖多组上肢/躯干肌群[7] | 穿戴形态完整，能同步观察肌电和运动 | 公开价格较高且需额外配套；固定服装/肌群形态与普通用户使用成本较高 |
| Jurado等2025年腹部训练系统 | BlazePose + MyoWare + ESP32 + App，评估仰卧起坐角度和腹部信号[8] | 工程链路完整、低成本、可解释 | 单场景、阈值规则、小规模验证；EMG深度建模与跨人、跨环境、跨动作泛化不足 |

## 4.3 竞争策略

本项目不应宣传“比所有专业设备更准确”，而应建立以下差异：

1. **视觉与肌电互补**：同时观察外部动作和内部肌肉激活；
2. **泛化作为核心指标**：重点报告跨被试、跨视角、电极偏移与模态缺失表现；
3. **结果可理解**：从原始曲线升级为动作阶段、错误类型、肌群提示和纠正建议；
4. **分层产品形态**：消费者版使用单手机+少通道sEMG，机构版再增加多视角和IMU；
5. **以专业设备为采集与验证伙伴**：早期可使用现有科研设备采集和建立参考，不与其硬件能力直接竞争。

## 4.4 竞品分析的边界

公开产品材料通常不会披露训练集划分、跨被试性能、具体算法或临床验证细节。因此，关于竞品“泛化能力不足”的表述只能写为：

> 公开材料未见其以跨被试、跨视角和电极偏移为核心公开指标。

不应在申报书中无依据地断言某产品一定无法泛化。

# 五、技术路线与研究方案

## 5.1 总体技术流程

**数据采集**

多视角短视频 / 单手机视频 + 同步sEMG + 可选IMU

↓

**预处理与同步**

视频时间戳、姿态关键点、动作重复分割；sEMG滤波、质量控制与归一化；IMU去噪与姿态估计

↓

**多分支表征**

视觉/姿态分支 + sEMG时序分支 + 可选IMU分支

↓

**跨模态融合与泛化**

阶段对齐、交叉注意力/门控融合、域不变表征、模态缺失训练、少量校准

↓

**多任务输出**

动作质量分数 + 错误类型 + 肌肉激活/平衡 + 阶段定位 + 置信度

↓

**可解释反馈与报告**

图形化提示、纠正建议、训练组内变化和长期趋势

## 5.2 视觉与姿态分支

项目不采用“任意三张静态照片直接判分”作为主研究方案。动作质量具有明显时序性，应优先使用完整短视频，再从中抽取关键帧。

建议流程：

1. 使用MediaPipe Pose Landmarker或同类模型提取人体关键点。MediaPipe能够从图像或视频输出33个身体关键点及三维世界坐标，可用于姿态与动作分析。[9]
2. 通过关键点速度、髋/膝/踝角度和动作周期识别，切分每次重复及关键阶段；
3. 形成两类视觉输入：
   - RGB/短视频特征，用于处理器械、遮挡和整体外观；
   - 2D/3D骨架、关节角度和轨迹，用于提供稳定、可解释的结构特征；
4. 多视角训练时进行跨视角注意力或特征汇聚；
5. 部署时采用“视角随机丢弃”和教师—学生蒸馏，使模型在单视角下也能工作。

“三张图”的产品构想可保留为**多视角关键帧模式**：系统从每个视角的短视频中自动选择起始、最低点和高风险阶段，而不是让用户手动拍三张互不同步的照片。

## 5.3 sEMG分支

### 信号采集

- 研究期优先使用原始sEMG，而不是只有低频包络输出的简化传感器；
- 采样率依据设备、数据集及目标频段确定，原则上应满足原始sEMG分析需要；
- 采用统一皮肤准备、贴片方向、肌肉定位和固定方式；
- 参考SENIAM对双极电极、20 mm中心间距、沿肌纤维方向放置和固定的建议。[10]

### 预处理

1. 信号质量检查：断连、饱和、过大运动伪迹、工频干扰；
2. 带通及工频抑制，具体参数依据设备采样率和信号特性确定；
3. 动作阶段同步与窗口切分；
4. 幅值归一化：MVC、session内标准化或稳健分位数归一化；
5. 数据增强：幅值缩放、时间扰动、通道丢弃、噪声注入、电极偏移模拟；
6. 同时保留原始时序、包络、时频图及RMS/MAV/WL等可解释特征作为候选输入。

### 特征学习

sEMG分支可采用团队已有泛化模型作为骨干，完成：

- 局部时序与频谱特征提取；
- 多肌肉协同关系建模；
- 动作阶段内激活顺序分析；
- 左右侧或主动肌—拮抗肌相对关系学习；
- 受试者无关、session无关表征学习。

## 5.4 IMU分支（可选增强）

IMU由三轴加速度计、三轴陀螺仪及可选磁力计构成，用于提供加速度、角速度、姿态和运动稳定性。FLEX不包含IMU，因此IMU不应成为第一阶段复现的前置条件。

建议策略：

- 学术主线先完成“视觉 + sEMG”；
- 自采MVP如发现视觉受遮挡或动态节奏难以稳定提取，再增加1—3个IMU；
- IMU优先放置在躯干、大腿或训练器械上，用于动作阶段、速度和稳定性；
- 通过时间戳和同步事件对齐视频、sEMG与IMU。

## 5.5 多模态融合

不建议只做简单拼接。可依次比较：

1. **晚期融合基线**：各模态独立预测后加权；
2. **门控融合**：模型根据每个模态的信号质量动态分配权重；
3. **跨模态注意力**：用动作阶段或骨架特征查询对应sEMG片段；
4. **一致性约束**：约束动作阶段、肌肉激活和错误类型之间的生物力学一致性；
5. **缺失模态训练**：随机丢失视角、通道或整个模态，使系统具有降级能力；
6. **多任务学习**：同时预测质量分数、错误类型、动作阶段和肌肉激活特征。

## 5.6 泛化模块

本项目的论文贡献应集中于以下至少两项，而不是简单强调“使用了Transformer”：

### 跨被试泛化

以受试者为分组单位进行训练/测试隔离。主实验采用Leave-One-Subject-Out或GroupKFold，严禁把同一受试者的不同重复随机分到训练集与测试集，避免数据泄漏。Leave-One-Group-Out可使每次测试完整留出一个受试者组。[11]

### 跨视角泛化

- 训练视角和测试视角分离；
- 随机旋转、裁剪、遮挡和背景扰动；
- 多视角教师向单视角学生蒸馏；
- 使用骨架结构和世界坐标降低外观依赖。

### sEMG电极偏移与跨天泛化

- 标准化贴片流程与位置记录；
- 训练时进行通道扰动、偏移模拟和幅值变化增强；
- 使用域不变对比学习、统计分布对齐或测试时自适应；
- 允许30—60秒轻量校准，并比较零校准与少量校准。

### 跨负重、速度和训练水平

- 按负重区间、动作速度、训练水平分层；
- 设置未见负重或未见技能等级测试；
- 将体型、负重、训练水平作为条件信息，而不是让模型把它们误当作动作质量。

### 模态缺失泛化

- 训练时随机丢弃部分视角或肌电通道；
- 输出模态质量分和预测置信度；
- 明确提示用户“当前信号不足，建议重贴电极或调整拍摄角度”，避免强行给出高置信评分。

## 5.7 输出与可解释反馈

系统输出分为四层：

1. **总体分数**：动作质量连续分数及置信区间；
2. **错误类型**：例如深度不足、躯干过度前倾、左右偏移、节奏不稳；
3. **肌肉层提示**：目标肌群激活不足、左右差异、代偿趋势；
4. **阶段定位**：指出错误发生在第几次重复和哪个动作阶段。

反馈模板应由训练规则或知识图谱约束，避免让生成式模型直接编造生物力学结论。语言模型可用于把已确认的结构化结果转成自然语言，但不能代替底层评分与安全规则。

# 七、实验设计与评价指标

## 7.1 数据划分原则

1. 受试者级隔离，杜绝同一人的不同重复跨训练/测试集合；
2. 建立标准随机划分、跨被试、跨视角、跨负重、跨技能等级、跨天和电极偏移多个测试集；
3. 对所有模型使用相同数据划分与随机种子；
4. 至少运行3—5次并报告均值、标准差和显著性分析；
5. 单独报告各训练水平、体型和性别组的表现，避免总体均值掩盖系统性偏差。

## 7.2 基线模型

- 视觉：2D/3D CNN、Video Transformer或公开AQA基线；
- 姿态：ST-GCN、TCN或骨架Transformer；
- sEMG：1D-CNN、LSTM/GRU、TCN、Transformer；
- 融合：简单拼接、晚期加权；
- 泛化：无泛化模块、领域对齐、对比学习、测试时自适应；
- 产品基线：MediaPipe关键点 + 规则阈值。

## 7.3 主要指标

### 连续动作质量评分

- Spearman等级相关系数；
- Pearson相关系数；
- MAE、RMSE；
- 分数校准误差。

### 错误类型识别

- Macro-F1、Balanced Accuracy；
- 各错误类型召回率；
- 多标签mAP；
- 混淆矩阵。

### 泛化与鲁棒性

- 跨被试相对性能下降；
- 未见视角、负重和技能等级表现；
- 电极偏移、通道丢失和模态缺失下的性能曲线；
- 零校准与少量校准对比。

### 产品指标

- 每次动作组结束后反馈延迟；
- 有效信号率、重贴率；
- 用户佩戴和采集时间；
- 建议可理解性和教练一致性；
- 移动端或边缘端资源占用。

## 7.4 建议验收目标

以下仅为立项阶段的建议目标，需在完成公开基线复现后锁定：

1. 跨被试设置下，核心评分指标显著优于相同骨干网络的无泛化版本；
2. 视觉+sEMG融合显著优于视觉单模态与sEMG单模态；
3. 缺失一个视角或一个sEMG通道时，系统仍能给出稳定的降级结果；
4. 能对深蹲完成重复分割、质量评分、至少3类错误提示和肌肉激活展示；
5. 在自建小样本数据上完成跨人、跨天或轻微电极偏移中的至少两项验证；
6. 形成可重复运行的现场演示，动作组结束后数秒内给出反馈。

# 八、自建数据与MVP方案

## 8.1 首轮数据采集

建议招募20—30名健康成年人，每人分两天采集。具体人数应结合伦理、经费与统计功效重新核定。

### 动作与条件

- 深蹲：标准、深度不足、躯干前倾、轻度左右偏移；
- 速度：慢、中；
- 负重：徒手或低风险轻负重；
- session：同日重复 + 隔日重新贴片；
- 电极：标准位置 + 预先定义的轻微偏移条件。

错误动作必须由专业人员设计为**低风险、轻度模拟**，不要求志愿者进行危险负重或极端错误姿势。

## 8.2 建议传感器配置

MVP可从单侧或双侧的少通道方案开始。示例：

- 股外侧肌或股直肌；
- 股二头肌；
- 臀大肌；
- 竖脊肌；
- 可选：躯干/大腿IMU；
- 视频：正面或45°主视角；专业版增加侧面。

实际肌肉选择应由运动科学或解剖专业人员确定，不能只按算法方便性决定。

## 8.3 标签设计

采用三层标签：

1. **动作与阶段标签**：动作类别、重复序号、离心/底部/向心阶段；
2. **错误类型标签**：深度不足、躯干前倾、左右偏移等；
3. **连续质量分数**：按标准化评分表由两名及以上标注者独立评分。

同时记录：

- 训练经验、身高体重等必要协变量；
- 负重、速度、摄像头角度、距离和光照；
- 电极位置、皮肤准备、设备编号和信号质量；
- 不适、疼痛和中止情况。

对双人标注结果计算一致性；分歧样本由第三位专家复核。

## 8.4 隐私与安全

- 采集前完成知情同意和伦理流程；
- 视频、身份信息和生理数据分开存储；
- 对展示数据做人脸模糊或只保留骨架；
- 允许参与者撤回数据；
- 训练负重保持低风险，设置热身、休息和中止标准；
- 现场应由具备训练指导能力的人员监督；
- 产品报告使用“动作风险提示”“肌肉激活异常模式”等表述，不输出疾病诊断。

| “标准动作”存在个体差异 | 标签主观、模型可能惩罚合理变体 | 引入教练规则、体型和活动度条件；输出分项而非单一绝对分；双人标注和一致性检验 |
| sEMG幅值不等于肌肉绝对力量 | 结论被夸大 | 只描述相对激活、协同和趋势；若要估计力，必须加入力传感器并独立校准验证 |
| 缺乏真实损伤长期结局 | 无法证明“预防受伤” | 不宣称损伤预测；输出动作质量和潜在高风险模式；未来通过长期随访验证 |
| 模型过大、实时性不足 | 无法现场演示或端侧运行 | 先做组后分析；再进行蒸馏、量化和通道削减；把姿态提取放到端侧、复杂融合放到本地服务器 |
| 多模态系统故障点多 | 演示不稳定 | 模块化设计；每个模态可单独运行；缺失模态降级；竞赛准备录屏和离线回放备份 |
| 生理数据与视频隐私 | 伦理和用户接受度受影响 | 最小化采集；本地提取骨架；原视频可选不上传；加密存储、权限控制和撤回机制 |

# 十一、创新点

## 11.1 需求创新

不再把健身动作评估等同于“人体关键点角度判断”，而是将外部运动学与内部肌肉激活联合建模，回答“姿态是否合理”和“肌肉是否用对”两个问题。

## 11.2 方法创新

将团队已有的泛化型生物电模型迁移到多视角视觉—sEMG AQA任务，重点解决跨被试、跨视角、电极偏移和模态缺失，而不是只追求固定划分上的高准确率。

## 11.3 评价创新

采用受试者级隔离、跨视角、跨负重、跨天和电极偏移等真实条件进行验证，避免仅使用随机样本划分导致虚高结果。

## 11.4 产品创新

形成“单手机+少通道sEMG”的轻量版与“多视角+sEMG+可选IMU”的机构版，研究期依靠多模态上限，产品期通过蒸馏和降级降低使用门槛。

## 11.5 解释创新

输出动作阶段、错误类型、相关肌群、左右差异和纠正建议，不只给出不可解释的总分。

# 十二、商业化与竞赛表达

## 12.1 价值主张

> 纯视觉只能看动作外观，专业肌电又难以被普通训练者理解。肌镜智评把姿态、肌肉激活和泛化模型结合，给训练者与教练提供“看得见动作、看得见发力”的量化反馈。

## 12.2 初期客户

优先采用B2B2C路径：

1. 高校体育教学与运动科学实验室；
2. 中小型健身房、私教工作室和体能训练机构；
3. 需要训练评估报告的运动康复机构。

直接面向所有消费者销售硬件不是第一优先，因为电极贴附、佩戴教学和解释责任会显著增加获客与服务成本。

## 12.3 产品形态

- 传感端：2—4通道sEMG贴片/绑带，可选IMU；
- 视觉端：用户手机或机构固定摄像头；
- 软件端：动作分析、训练报告、教练端管理；
- 算法端：动作分割、姿态评分、肌电分析、泛化融合和解释模块。

## 12.4 商业模式

- 机构软件订阅 + 传感器套件；
- 教练/机构按账号或使用次数付费；
- 高校与科研机构算法分析服务；
- 后续可提供SDK/API，与智能健身镜或训练设备合作。

## 12.5 竞赛答辩中应主动承认的边界

1. FLEX只能用于学术研究，商业数据需要自建；
2. 第一代产品不会覆盖所有动作；
3. sEMG反映肌肉电活动，不直接等于绝对力量；
4. 系统提供动作质量和风险模式提示，不是医疗诊断；
5. 多视角和多通道提升效果，但产品必须通过少视角、少通道降低使用门槛。

主动说明这些边界会提升项目可信度，而不是削弱项目。

# 十三、预期成果

## 13.1 科研成果

- 一套跨个体泛化的视觉—sEMG多模态动作质量评估模型；
- 一套标准化数据处理和受试者级评测流程；
- 至少一篇论文初稿或投稿；
- 模态融合、泛化和可解释性消融实验；
- 自建小型同步视频—sEMG数据及数据说明。

## 13.2 工程成果

- 深蹲动作评估MVP；
- 传感器连接、信号质量检查和同步模块；
- 动作阶段、姿态错误、肌肉激活和综合反馈界面；
- 单视角/少通道降级能力；
- 可用于路演的演示视频和现场系统。

## 13.3 创赛与知识产权成果

- 完整商业计划与竞品分析；
- 软件著作权材料；
- 根据检索结果与真实创新申请发明专利或实用新型；
- 创新创业竞赛项目书、路演PPT和答辩问答库。
