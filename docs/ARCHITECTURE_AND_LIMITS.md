# 架构、边界与验收

## 数据流

```text
采集端 EMG 250 Hz / IMU 112 Hz 独立时间轴
        |
        v
HDF5 v3检查 -> 对齐到内部200 Hz -> 200 ms因果窗口 / 40 ms步长
        |                                      |
        +-------------+------------------------+
                      |
          +-----------+-----------+
          |                       |
   EMG 校准与环形空间模式      IMU 零偏/重力/人体坐标
          |                       |
   H 分类 + P_hand            D 分类 + P_arm
          +-----------+-----------+
                      |
              A / M / C / Q
                      |
          OSC v2（可同时发旧协议）
```

经典基线的 D/H 是两个独立 RBF-SVM；LDA 只作为最低基准。自研模型使用两个
因果 TCN 分支，D 以 IMU 为主、H 以 EMG 为主。弱门控允许另一模态提供辅助证据，
辅助单模态头、门控惩罚和模态丢弃降低模型偷学动作组合共现的风险。
新 TCN 使用 `1/2/4/8` 四级膨胀，200 Hz 下末端感受野约 175 ms；旧模型产物仍按
原 `1/2/4` 拓扑加载。辅助头高置信反对融合头时，分类结果进入 Unknown。
新 EMG 编码器并行使用保留舒适强度的幅值输入和按窗口全局 RMS 归一化的空间形状
输入，再由弱门控融合；旧 `.pt` 自动关闭新增分支以保持参数拓扑。

经典模型支持有标签的会话末层适配。它只优化温度校准后 logits 上的有界 bias，
要求全部模型类别达到最少样本数，不更新 SVM/特征标准化器，并强制另存产物，因而
可以回滚。无标签 TTA 和主干在线更新仍未上线。

## 已实现的约束

- 训练、验证、最终测试固定为 Session 1–2 / 3 / 4，窗口不能跨 trial 拆分。
- SVM/TCN 训练按 session、trial 分层等权，trial 内重叠窗口共享该 trial 的权重；
  Session 3 的温度、拒识阈值和汇总指标使用相同权重，混淆矩阵保留原始窗口计数。
  LDA 仅为未加权诊断下限。
- Session 3 单独完成温度校准和覆盖率至少 90% 的拒识阈值选择。
- 方向与手势由独立状态机确认两个连续候选帧；低质量时进入 Unknown。
- `C` 仅比较相同 D/H/双阶段条件下的 A、M 和 onset lag，不回写分类结果。
- 高采样率外部 EMG 只通过抗混叠多相重采样进入；不同电极布局不做伪空间插值。
- Session 4 首次打开后写入结果和模型哈希，此后默认锁定。
- packet丢失、质量闸门、逐通道质量与IMU插值状态会进入训练筛选和实时Unknown。
- SVM 使用按预测类别的稳健特征域守卫；低置信、域漂移和神经头冲突有独立质量标志。
- 非有限 EMG/IMU 只做防崩溃的安全数值替换，原始异常仍降低信号质量；受影响的
  输出头拒识为 Unknown，不把替换值当成真实观测。
- 已评估但低 margin 的 EMG shift 只拒绝 H；超限的人体坐标拟合残差只拒绝 D，
  二者均标记 `CALIBRATION_UNCERTAIN`，未评估的旧校准保持兼容。
- Open 在已观察到 onset 后具有短时姿态记忆，持续 Neutral 证据才触发 Release。
- 评估报告逐类别 coverage 和 risk–coverage；模型与校准契约不兼容时拒绝启动。
- 每次实时服务默认生成独立审计包；运行 manifest 绑定模型/校准哈希和配置，原子
  health 快照记录 Unknown、质量原因、错误及处理延迟 P50/P95，逐帧 CSV 带 run ID
  和序号并周期性同步到磁盘。该处理延迟是分类服务内部延迟，不替代端到端反馈延迟。
- 新训练模型只标记为 `development_unvalidated`，无状态旧产物标记为
  `legacy_unspecified`；运行manifest不会因为模型可加载就赋予正式模型资格。

## 当前不能声称的内容

- 没有真实四 session 数据时，不能声称达到 F1、联合准确率或 300 ms 延迟目标。
- A 是个体校准后的相对激活，不是绝对肌力；M 不是位移、速度或机械功率。
- C 是条件异常提示，不是医学判断。首版样本不足时必须输出 Unknown。
- 一个腕带和表面 EMG 不足以估计完整关节力矩或肌骨动力学。
- 外部数据的许可证、具体列名和设备版本必须在实际下载时再次核对；登记表不是
  下载站点条款的替代品。
- HDF5 cue只代表界面提示。没有人工或算法复核的生理onset时，只使用带安全边界
  的保守稳定区间，不能据此声称测得真实神经肌肉延迟。

## 冻结前检查

1. `validate-dataset --formal` 无问题，且四个校准文件齐全。
2. 只根据 Session 3 选择 SVM/神经模型、阈值和状态机参数。
3. 检查 D/H 单模态消融与双分支结果；若融合提升只来自固定组合共现，不采用。
4. 冻结代码、模型和配置，保存模型哈希。
5. 最后一次运行 Session 4；不要因结果不理想返回调整模型。

冻结前先保存 validation evidence，再运行 `deployment-check`。检查器把模型哈希与
完整trial/校准数据指纹绑定，并要求正式协议、完整类别和v1指标同时通过；任何旧
参考结果、错误split或哈希不一致都会返回 `blocked`。`freeze-model` 不信任外部
readiness文件，而是重新运行门禁；成功后另存 `formal_frozen` 产物和四重哈希收据，
失败时不产生目标模型。现有旧参考数据会被该流程阻止。

正式部署使用 `package-deployment` 建立新目录，包含模型、冻结收据、会话校准、
验证证据、可选C模型与 `deployment.json`。清单同时固定输入/输出地址、端口和兼容
协议开关。打包和 `verify-deployment` 都会检查成员哈希、验证报告权重口径、精确配置
类型、模型正式状态、模型—收据—报告来源链及运行时加载契约。正式演示只用
`serve-deployment`，启动前再次验证清单并把清单哈希写入运行审计；接受散落
`--model` / `--calibration` 的 `serve` 仅用于开发调试。
