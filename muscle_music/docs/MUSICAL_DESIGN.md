# 悦耳度与个性化设计

项目首先要像一件乐器，其次才是传感器演示。系统没有让动作直接决定任意音高，而是让动作在已经写好的音乐语法中选择和改变材料。这样做会牺牲一部分完全自由的随机性，但能显著提高现场稳定性，也能让第一次使用的人在一分钟内得到完整作品。

每首作品使用固定速度、四四拍和四小节和声循环。调式从自然小调、多利亚和小调五声音阶中选择。鼓保留底鼓与军鼓骨架；贝斯围绕和弦根音、五度和少量经过音；和弦采用就近转位；旋律以一个短动机为核心，并在关键强拍落到当前和弦音；琶音只重排和弦音；环境声部使用稀疏长音。六个声部的音域与职责互不重叠。

再次进入同一方向时，原始动机种子保持不变。第一阶段建立基础，第二阶段改变节奏落点，第三阶段加入装饰与八度发展，第四阶段形成较密的高潮。第四阶段之后只变动非强拍装饰音，关键强拍、和声和原动机仍被保留。这样能同时获得可听变化和主题连续性。

当已开启声部超过三个，系统开始收紧装饰音预算并轻微降低各轨表达电平。强拍、底鼓、军鼓等结构音不会被删，弱拍装饰音会根据当前动作能量选择性出现。这个规则是六轨同时播放时仍能保持清晰的关键。

个性化分为声部特征和作品特征。每个方向单独累计运动强度、肌电激活和保持时长，决定该声部的密度、力度、亮度与连奏。全部方向的统计再汇总成作品特征，使后加入的声部带有同一用户的总体演奏倾向。画面用运动、肌电、连奏和复杂度四个连续量，以及一个两词标签展示结果。

个性化不等同于随机。会话随机种子只负责选择初始调性和基础动机；同一声部的动机种子在一首作品内不变。用户动作只改变有明确听感含义的参数，而且始终受到调性、和声、节拍、音域和密度约束。后续用户研究应分别评价悦耳度、动作与声音对应感、不同用户作品的可辨差异，以及同一用户重复操作时主题是否仍可识别。

首轮盲听建议比较三种方案：完全随机音符、只有音乐约束但没有动作个性化、完整系统。每名参与者评价连贯性、悦耳度、丰富度、个性化感和动作反馈感。完整系统至少应在悦耳度上明显优于完全随机方案，并在个性化感上优于无个性化方案。
