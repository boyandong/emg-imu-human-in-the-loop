# 现场演示流程

工作人员先让用户戴好手环，保持手臂自然放松两秒，再自然握紧一次，用于手环程序完成本次佩戴的强度归一化。屏幕上只保留一句操作提示：食指捏合开始，六个方向加入声音，再做一次让声音发展。

用户食指捏合后会看到一拍倒计时。建议引导顺序为前、下、左、右、上、后，这样先出现鼓和贝斯，再加入和声与旋律，最后补环境层，作品通常更容易听。用户不必严格遵守顺序，自由操作也是系统的一部分。

六个声部出现后，请用户挑一个喜欢的方向再做一次，并有意改变动作力度。屏幕会显示该声部从基础进入节奏变化或装饰发展，下一小节能听到差异。这一步是演示的重点，因为它能说明系统不是六个开关，而是一个可以继续演奏的乐器。

最后让用户再次食指捏合，结束并保留本次作品的画面摘要。整个过程控制在一分钟左右。下一位体验者食指捏合开始时，系统会自动建立新的调性与空白编曲，不需要工作人员执行额外的重置动作。

现场至少展示四个数字：接口到视觉反馈延迟、MIDI 调度误差、当前声部数量和误触次数。不要只显示分类准确率。观众最关心的是动作之后有没有立刻反馈、音乐是否真的变化，以及自然活动会不会乱触发。
