# Remaining evidence after the available-data work (2026-09-24)

This is a dependency list, not a claim that the Feature Bank goal is complete. The row-by-row state remains in [`REQUIREMENT_AUDIT.csv`](REQUIREMENT_AUDIT.csv); `partial` means the available experiment answers only a narrower question. The new public [GRABMyo cross-day screen](../benchmarks/grabmyo_crossday/REPORT.md) adds genuine eight-channel, three-day evidence, but it does not remove the dependencies below.

| Dependency | Affected requirements | Why the available evidence cannot settle it | Concrete route to completion |
|---|---|---|---|
| Exact old DS2 experiment identity and historical B0/X1-H/X2 results | PRE-1, PRE-ART, GOAL-ST2/3/4, EXACT-FAMILY | The publisher's 2026-09-25 v9 release now supplies a trial-exact force-code mapping for all 2,863 public raw trials; a fixed new F0/F1 cross-user screen is complete. It does not establish that the old experiments used this exact archive, split, preprocessing, model states or formulas. | Keep the [new public-v9 study](../benchmarks/discovery/public_ds2_force_v9/REPORT.md) separate. Recover dated old run manifests/code/checkpoints or sufficient input/output fingerprints before claiming historical replication; otherwise retire the equivalence claim. |
| Exact validated historical X1-H, RLCS, CES and Frequency implementation | GOAL-ST2/3/4, GOAL-ART2/3/4/6, EXACT-FAMILY, QUESTION-B/C/D | The accessible current GitHub repositories and local history do not contain the old source definitions and fitted states. This is **not a blocker to forward development**: a fully independent [`new bank v1`](../benchmarks/new_bank_v1/REPORT.md) now implements four eight-channel families and has public force/wearing plus exploratory own-device screens. Its outcomes cannot be labelled as the old result. | Continue only under new versioned names. The validation-selected combinations fail to improve final macro-F1, so acquire a new cohort/continuous own-device session before model selection or deployment. Only old state/schema or input/output examples could establish exact historical equivalence; otherwise retire that claim. |
| Multi-person, multi-day **own-device** eight-channel recordings | GOAL-ROBUST, GOAL-CAP, QUESTION-A/F/G/H | The Song device dataset is one participant and four sessions on one date. Public GRABMyo has different hardware, 2048 Hz and electrode geometry. Neither supports a claim about this device's cross-user/day performance. | Collect consented, labelled rest/pinch/fist/open trials from multiple users on at least two dates, with electrode removal/reapplication logged, recording channel map, gain, packet loss, IMU units/rate and trial boundaries. Freeze user/day splits before analysis. |
| Continuous live recognition and measured hardware failure modes | GOAL-ROBUST, GOAL-CAL, QUESTION-A/G/H | Saved labelled trials and synthetic corruptions cannot measure onset latency, false-rest/open oscillation, dropout, saturation, motion artefacts, or real calibration time in use. The current desktop shortcut/model-load smoke test is not a human-in-loop recognition study. | Run a time-stamped device session with ground-truth cue/onset/offset and raw packet capture; report event-level confusion, latency, false activations and per-action recall. Record actual calibration elapsed time and controlled cable/electrode/IMU disturbance trials. |
| Separated force, posture, speed, day and wearing interactions | GOAL-ROBUST, GOAL-ST4, QUESTION-C/F/G | Available public sources each manipulate only some factors; UniBo posture is oracle-labelled and confounded with day/reapplication, MANUS speed with session, and Song cues are not measured posture. A complete independent factorial result cannot be inferred by pooling incompatible data. | Acquire a controlled crossed protocol or release with factor labels, enough repeated trials and stable channel/IMU metadata. Preregister interaction cells and compare matched source/final splits; report unsupported cells as N/A until then. |
| Original pre-training selection trail and exhaustive historic-output audit | PRE-2, GOAL-LEAK, GOAL-ART1/2/3/4/5/6, LATE-PROB | Current candidate A–H scores are transparently retrospective. Existing source-only leakage checks and replay cover stated models and budgets, but cannot retroactively prove the original decision time or unseen historical probability paths. | Recover dated original scorecards/configs/commits and model outputs. For each restored path, replay source OOF preprocessing, class order, probability calibration and target exclusion; regenerate required CSVs from frozen raw predictions. |

Public DS2 v9 now has verified force codes independently of GRABMyo. Neither that update nor GRABMyo proves old-run identity, own-device cross-day accuracy, or a product acceptance threshold. The trial-level GRABMyo F0 result is positive for a limited public four-class screen, while its two added feature arms did not improve final-day metrics.
