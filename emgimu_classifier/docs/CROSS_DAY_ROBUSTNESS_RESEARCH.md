# EMG–IMU 跨日鲁棒性：采集与分类程序联合优化研究

更新日期：2026-09-10
适用范围：当前 8 通道环形前臂 sEMG + 单个 6 轴 IMU（加速度计、陀螺仪），EMG 实际约 250 Hz、IMU 实际约 112 Hz；不以更换硬件为首版前提。

> 分类器实现进度：新校准已支持全局尺度、多手势 shift 候选误差与 margin、人体
> 坐标残差和旧 JSON 契约兼容；SVM 已加入类条件域漂移拒识；评估已加入逐类别
> coverage 与 risk–coverage；Open 已加入释放滞后记忆；神经辅助头冲突会拒识。
> 神经 EMG 编码器已加入幅值/空间形状双表征；SVM 已提供覆盖全类别、有界、另存
> 产物的末层 bias 会话适配。本文其余采集、数据补全和训练采样建议仍是待办。

## 1. 执行结论

**不能把当前问题概括成“主要在采集层，不在代码层”。** 现有实验只能证明从同日验证到跨日重戴后发生了明显的分布变化：SVM 的方向 macro-F1 从 0.735 降到 0.514，手势 macro-F1 从 0.715 降到 0.482，联合准确率从 0.619 降到 0.382；同时置信度校准也恶化。它没有把电极重戴、肌肉状态、动作执行差异、时间对齐误差和校准算法逐项隔离，因此不能据此给某一层“定责”。详见现有[旧数据验证报告](../artifacts/reference_validation/VALIDATION_REPORT.md)。

对本项目最合理的判断是：

1. **必须优化采集程序。** 目的不是要求人每次佩戴和发力都完美，而是记录真实时间、自动发现坏数据、量化每次佩戴的偏移，并让失败的校准块立即重做。
2. **必须优化分类与校准程序。** 8 通道腕带的旋转、局部位移、接触差异和肌肉状态变化不可能完全靠操作规范消除；模型必须在训练和推理时把它们当作“正常扰动”。电极重戴导致性能下降是长期使用 sEMG 腕带的已知核心问题，而非本项目独有现象。[Young 等人的电极位移研究](https://pubmed.ncbi.nlm.nih.gov/21659017/)和一项 30 次、40–42 天的八通道腕带研究都观察到显著的跨日/位置退化。[长期腕带研究](https://www.sciencedirect.com/science/article/pii/S1746809420301373)
3. **暂时不应把主要精力放在更大的神经网络或无监督 TTA。** 旧数据中双分支 TCN 未超过 SVM，说明当前瓶颈不是单纯模型容量。第一优先级应是可审计的时间轴、校准质量、跨 session 训练和受约束的会话适配。
4. **250 Hz 不是“采坏了”。** 2000 Hz 是配置/元数据误写，硬件实际目标就是约 250 Hz。250 Hz 对 RMS、MAV、WL、ZC、SSC、包络与 onset 等首版特征可以使用；代价是奈奎斯特上限为 125 Hz，不能恢复或解释更高频的 EMG 频谱。采集前的硬件抗混叠滤波仍然重要。研究显示典型幅值和时序量不一定因较低采样率完全失效，但低于所需信号带宽时会丢失信息。[采样率与 EMG 时序/幅值研究](https://pubmed.ncbi.nlm.nih.gov/12828904/)、[ISEK EMG 报告标准](https://isek.org/emg-standards/)

因此首版路线应是：

> **可重复但不苛求完美的采集 + 每次佩戴的显式校准 + 面向跨日扰动训练的分类器 + 低质量/低置信拒识。**

## 2. 当前硬件能看见什么，不能看见什么

算法上限首先由可观测性决定。软件可以降低噪声、利用历史状态和学习统计规律，但不能从不存在的传感信息中恢复真值。

| 状态 | 当前硬件的直接证据 | 可实现程度 | 固有限制 |
|---|---|---|---|
| `H` 手势 | 8 通道 sEMG 空间分布、强度及时间变化 | Fist/Pinch 较可行；Open 需阶段记忆 | Open 保持后 EMG 可能下降，与 Neutral 越来越相似；没有手指角度或压力传感器时，静态姿态不是始终可直接观测 |
| `D` 运动方向 | 线性加速度、角速度的方向与短时趋势 | 动作过程可行 | 单个前臂 IMU 不能可靠给出手在空间中的绝对位置；平移、前臂旋转和重力混合会互相干扰 |
| `A` 激活强度 | 归一化 EMG 包络/RMS | 可作为相对量 | 受皮肤接触、电极位置、发力水平、疲劳影响，不能解释为绝对肌力 |
| `P_hand` | EMG burst、持续激活、释放变化 | 可行但依赖状态机 | 仅用单窗口静态分类会丢失 Open 的 onset 证据 |
| `P_arm` | 加速度/角速度 onset、峰值、衰减 | 可行 | Hold 时 IMU 动态信号接近静止，必须靠历史状态维持阶段 |
| `M` 运动强度 | 线性加速度和角速度能量 | 可作为相对量 | 不是位移、速度或机械功率；加速度二次积分会快速漂移 |
| `C` 一致性 | EMG 激活、IMU 运动及 onset lag | 可作异常提示 | “EMG 强、IMU 弱”可能是正常等长收缩，不能直接判为错误或医学异常 |

### 2.1 单个 6 轴 IMU 的坐标限制

加速度计提供重力参考，因此静止或低动态时能约束俯仰和横滚；陀螺仪提供短时角速度，但偏置积分会漂移。没有磁力计或其他航向参考时，绝对 yaw/人体前向不能自动长期恢复。姿态滤波可以改善噪声和偏置，却不会创造缺失的航向观测。[Mahony 等人的低成本 IMU 姿态观测器](https://doi.org/10.1109/TAC.2008.923738)

这意味着每次佩戴都需要至少一个“人体前向”和一个“人体右向”引导动作来建立相对人体坐标；不能只依赖设备 XYZ，也不能期望一次校准永久有效。

### 2.2 8 通道环形 EMG 的空间限制

八通道能表达环绕前臂的粗粒度肌肉激活图，但相邻通道间隔较大。腕带恰好转过一个通道间距时，整数循环平移可以补偿；转过半个通道、沿前臂上下移动、松紧改变或局部接触变化时，单纯 `np.roll` 无法完全恢复。电极相对肌纤维方向与横向位移都会改变信号和分类性能。[SENIAM 放置与固定建议](https://www.seniam.org/fixation.htm)、[电极尺寸/方向/位移实验](https://pubmed.ncbi.nlm.nih.gov/21659017/)

所以“固定好腕带”是必要条件，但不是完整方案。分类器必须见过并容忍合理的通道旋转、单通道失效和幅值变化。

## 3. 跨日下降可能来自哪里

下面按本项目的证据强度排序，而不是按理论上是否可能排序。

### 3.1 高概率：腕带空间位置和接触改变

现有校准只搜索 0–7 的整数环形偏移，而且依据合并后的手势能量图选择一个 shift。风险有三点：

- 小于一个通道间距的旋转不可被整数 shift 表达；
- 沿前臂轴向的位移不是环形平移；
- 把 Fist、Pinch、Open 合并成一个能量轮廓后，轮廓可能过于平坦或由最强手势主导，导致 shift 不可辨识。

文献中增加包含电极位移的训练 session 能改善跨 session 表现，且使用多个训练 session 通常优于单 session。[考虑电极位移的手势研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8624257/)

### 3.2 高概率：校准尺度改变了空间判别信息

旧参考校准先计算每通道静息中心，再用所有校准手势的第 95 百分位逐通道缩放。
新拟合默认使用全局稳健尺度，并保留旧 JSON 的逐通道模式以兼容现有模型；正式
选择仍需未来 Session 3 消融验证。

EMG 归一化本来就是任务相关选择，并不存在一个对所有解释都最优的方法；跨次比较需要归一化，但参考动作和解释目标必须匹配。[Burden 的 EMG 归一化综述](https://pubmed.ncbi.nlm.nih.gov/20702112/)、[CEDE 归一化共识矩阵](https://www.sciencedirect.com/science/article/pii/S1050641120300808)

### 3.3 中高概率：动作姿势本身改变了 EMG

你们现在的新协议包含“移动同时 Pinch/Fist/Open”，这是正确方向，因为手臂位置会改变前臂 EMG 的统计分布。已有研究中，肢体位置变化使平均分类错误率从 3.8% 增至 18%；加入多位置训练或加速度信息后，错误率可降至约 5%。[Fougner 等人的 limb-position effect 研究](https://pubmed.ncbi.nlm.nih.gov/21846608/)

因此旧数据中的静止手势不能代表移动时同一手势。这里既不是采集员“做错”，也不是模型“写错”，而是训练分布没有覆盖部署分布。

### 3.4 中概率：发力、疲劳、出汗和日内状态变化

舒适握拳和捏合的幅值不会每天完全一致。运动或疲劳会改变 sEMG 特征，一项跨 session 实验中非运动组下降约 2.86%，运动组下降约 13.53%。[运动状态与跨 session 准确率研究](https://pubmed.ncbi.nlm.nih.gov/39199769/)

因此采集元数据应记录“过去一小时是否剧烈使用上肢、皮肤是否潮湿、是否明显疲劳”，并在正式 session 前安排短暂静息。模型增强也必须覆盖合理幅度变化。但不能用强制最大收缩追求一致，因为最大用力本身带来疲劳与安全/舒适问题。

### 3.5 中概率：多模态时间轴和包级到达时间不足够精细

2000 Hz 已确认是打错，真实 EMG 就是约 250 Hz，这不是硬件采样故障。但采集代码目前仍有两个结构性问题：

- 串口一次 `read` 得到的所有帧共用同一个 PC `received_ns`，它表示“这一批数据被读到”的时刻，不是每个样本真实采样时刻；
- EMG 文件主要依赖连续 `sample_index`，IMU 再绑定到当时的 EMG index；若一批数据同时到达、发生丢包或调度抖动，短时 onset lag 可能被扭曲。

无线/异步生理传感器存在时钟偏差与漂移，可靠方法通常使用设备端样本计数或时间戳与主机时钟建立仿射映射，而不是把主机批量到达时间当成逐样本采样时间。[BLE 多通道生物信号同步研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10144216/)

这对稳定区间的 D/H 分类影响可能有限，但会直接影响 `P`、EMG→IMU onset lag 和 `C`。

### 3.6 确定存在：置信度在跨日后失准

旧实验的 S06 ECE 明显高于 S05，说明相同的输出概率在第二天不再对应相同正确率。温度缩放能在固定验证分布上改善概率校准，但不能自动修复新的域偏移。[Guo 等人的温度缩放研究](https://proceedings.mlr.press/v70/guo17a/guo17a.pdf)

因此 `Unknown` 不能只看一次离线确定的最大概率阈值，还应结合输入质量、校准匹配残差和分布漂移分数。

## 4. 采集程序必须怎样优化

目标是把“无法避免的不完美”变成可检测、可量化、可补偿的数据，而不是把所有责任交给操作员。

### 4.1 P0：修正采样率和时间语义

1. 将配置、HDF5 元数据、训练模型清单和 UI 全部统一为真实标称 `250 Hz`；同时保存每个 session 的**实测有效采样率**，不要只存常量。
2. 每个 EMG 包保存设备序号、主机单调到达时间和 session sample index；如果设备协议无法提供源时间戳，就按包序号与已知采样周期重建包内样本时间，并用主机时间只估计慢速漂移。
3. EMG 和 IMU 分别保留原始时间轴；离线和实时阶段通过 timestamp 对齐到 25 Hz 输出帧，并附 `observed/interpolated/missing` 掩码。不要假装 IMU 原本也是 250 Hz。
4. 对重复包、逆序包、丢包和间隔异常做独立计数；不能只丢弃后继续当作连续数据。每个窗口计算丢失比例，超阈值就 `signal_quality=Bad`、D/H 为 `Unknown`。
5. 滤波器统一以 250 Hz 设计。现有 20–90 Hz 带通在奈奎斯特 125 Hz 下合理；50 Hz 陷波仍应只在校准测得明显工频污染时启用。还应向硬件方确认 ADC 前已有合适的模拟抗混叠限制；若没有，数字滤波无法撤销已经发生的混叠。

### 4.2 P0：采集前自动质量闸门

在正式 trial 前用 8 秒静息和短动作自动检查：

- 饱和/削顶比例；
- 平线通道和异常零值；
- 各通道静息噪声 MAD 或 95 分位；
- 50 Hz 相对能量；
- 动作时相对静息的 SNR；
- 相邻通道相关性异常（完全相同可能是通道复制，完全孤立可能是接触差）；
- EMG/IMU 实测频率、丢包率、乱序率和跨模态时间残差。

质量失败时只重做失败的校准块，不要开始正式 trial 后再靠人工剔除。SENIAM 同样强调定位、固定和连接测试是标准放置流程的一部分。[SENIAM 标准化放置流程](https://www.seniam.org/pdf/contents5.PDF)

### 4.3 P1：佩戴过程做成可重复的机械协议

在不换电子硬件的前提下，最有价值的“硬件优化”其实是低成本机械约束：

- 腕带标明 Channel 1 和朝向箭头；
- 用固定解剖标志确定腕带沿前臂的高度和环向起点；
- 固定左右臂、佩戴方向和通道顺序；
- 使用可复现的扣位或臂围刻度近似控制松紧；
- 佩戴后等待短时间稳定接触，再校准；
- 若允许，记录不含人脸的局部佩戴参考图，或至少记录刻度、扣位和 donning ID。

这不会消除所有偏移，但能把偏移限制到模型增强能覆盖的范围。

### 4.4 P1：把 60 秒校准改成“有反馈的测量”

建议时间表（允许 5–10 秒浮动）：

| 校准块 | 时间 | 用途 |
|---|---:|---|
| 自然静息 | 8 s | 中心、噪声、工频、重力和陀螺零偏 |
| Fist/Pinch/Open 各 2 次，每次 2 s，间隔 2 s 放松 | 24 s | 手势模板、舒适强度、环形 shift 共识 |
| Right–Left、Forward–Backward、Up–Down 各一个往返 | 20–24 s | 人体坐标、运动尺度、轴向符号 |
| 自动校验和必要的单块重做 | 4–8 s | 输出校准通过/失败和具体原因 |

关键变化：

- 不再只生成一份参数；同时输出 `shift_margin`、人体旋转拟合残差、每手势模板相似度、每通道 SNR 和质量等级。
- 三个手势分别估计 shift，再做有置信度的共识；若三个结果冲突，提示重新佩戴或重做，而不是静默选择一个 shift。
- 强度要求“舒适且可重复”，不是最大用力。两次重复差异过大时重做该手势。
- Session 4 的 60 秒块只更新预注册的 nuisance 参数，不更新分类权重或阈值；这样仍符合盲测协议。

### 4.5 P1：采集标签更贴近传感器能看到的状态

1. `D` 定义为**当前运动方向**，不是最终位置。到达终点后的 Hold，方向头应根据协议定义输出 None 或保持最后方向，但必须固定一种语义；建议 `D=None, P_arm=Hold`，避免让静止 IMU猜空间位置。
2. `Open` 必须是主动伸展，不能再把“自然松手”混入 Open。Open 的稳定姿态标签允许 EMG 下降，但 `P_hand` 必须从 onset 延续到 hold。
3. 提示时间不等于人体动作 onset。程序要保留 cue 时间，同时用 EMG/IMU 自动候选 onset，并允许人工抽查；训练稳定段至少避开 cue 与动作边界。
4. 新的 28 组合协议必须保留 `-200/0/+200 ms` 的相对起始偏移，避免模型通过固定先后顺序猜标签。

## 5. 分类与校准程序必须怎样优化

### 5.1 P0：先改校准表征，不急着换分类器

对当前逐通道 95 分位缩放做三组无泄漏消融：

1. **现状**：每通道手势 95 分位缩放；
2. **保空间比例方案（首选）**：每通道仅减静息中心并用静息噪声做质量修正，动作幅值用一个全局 robust scalar 归一化，从而保留八通道间相对强弱；
3. **双表征方案**：分类器同时输入“噪声标准化的绝对通道特征”和“每窗口相对能量/对数比”，让幅值与空间形状各走一条特征通路。

选择标准只看 Session 3 的跨佩戴表现，不看训练集。预计第三种最稳健，因为完全丢弃幅值会伤害 Fist/Pinch 区分，完全依赖绝对幅值又会受跨日尺度影响。

### 5.2 P0：环形对齐从单点答案改成概率与鲁棒训练

- 保存 8 个 shift 的匹配误差，而不是只保存 `argmin`；最佳与次佳差距太小时判定 shift 不可靠。
- 分别使用 Fist、Pinch、Open 模板求 shift，再用质量加权投票。
- 训练时加入 `roll ±1/±2` 的通道旋转、单通道 dropout、局部增益变化和噪声增强；精确整数 roll 仍作为几何正确的增强。
- 对小于通道间距的偏移，不把“插值通道”冒充真实电极。更稳妥的是让环形卷积/相邻通道汇聚学习局部不变性，同时保留原始通道分支。

### 5.3 P0：训练采样单位从窗口改为 session/trial

重叠窗口高度相关，因此：

- 先按 session 和 trial 固定 train/validation/test，再切窗口；
- 每个 mini-batch 或 SVM 样本权重先平衡 session，再平衡 trial 和类别，避免某个长 trial 用大量窗口主导模型；
- 训练增强必须在分区后进行，校准器、标准化器和特征选择都只在训练 session 拟合；
- Session 3 用于模型选择与阈值，Session 4 一次性评估。随机拆重叠窗口会夸大效果，时序数据泄漏研究也明确指出这种风险。[数据重叠泄漏综述与实验](https://doi.org/10.1007%2Fs10462-025-11326-3)

当前代码已实现 `equal_session_then_trial_v1`：每个 session 总权重相等，session 内
每个 trial 总权重相等，trial 内重叠窗口再均分权重。该权重进入 SVM/TCN 训练、
类别权重、SVM 域守卫以及 Session 3 温度/拒识选择。它修复统计口径，但尚无正式
四 Session 重训结果，不能据此宣称跨日指标已经提升。

### 5.4 P1：维持独立 D/H 头，但正确使用辅助模态

当前目标中 D 与 H 应保持独立主通路：

- D 主头只看人体坐标 IMU；可加入低权重 EMG onset/激活作为阶段辅助，不允许用某手势的统计共现直接猜方向。
- H 主头看 EMG；可加入 IMU 姿态/运动强度作为条件变量，以解决 limb-position effect，但通过 EMG-only 辅助头和模态 dropout 约束其不能只记方向。
- 继续保留 LDA 和 RBF-SVM。先让新的校准与采集使 SVM 跨 session 稳定，再比较 TCN。文献中的多位置训练和加速度融合确实能缓解位置效应，但并不要求首先使用深网络。[多位置训练研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5624523/)

### 5.5 P1：Open 用时序状态估计，不用单帧硬猜

当前硬件对“Open hold 后 EMG 下降”存在可观测性缺口。应采用：

1. Open onset 的伸展空间模式/burst 提供强证据；
2. onset 后进入 `P_hand=Active/Hold`；
3. 在没有明确 release、其他手势证据或超时前，H 可以维持 Open；
4. 若信号质量变差或持续出现相互矛盾证据，转 Unknown，而不是永久冻结；
5. 静息起始时没有历史证据，不能仅因手看起来张开而声称 Open，应该 Neutral/Unknown，取决于协议。

这也是之前“移动 MAV 阈值行动段”不适合作为手势分类器的原因：Neutral 和轻 Pinch 的幅值分布会重叠。包络阈值可以作为 onset/phase 的弱证据，但不能作为 H 的硬门控。

### 5.6 P1：Unknown 同时看置信度、质量和域偏移

推荐接受条件：

```text
accept_D = qD >= threshold_D
           and imu_quality_pass
           and body_calibration_residual <= limit
           and drift_score_D <= limit

accept_H = qH >= threshold_H
           and emg_quality_pass
           and ring_alignment_confident
           and drift_score_H <= limit
```

除了 ECE，还要画 risk–coverage 曲线：随着拒识增多，被接受样本的错误率是否稳定下降。选择性分类的核心就是用覆盖率换取更低的已接受风险。[选择性分类基础](https://jmlr.csail.mit.edu/papers/v11/el-yaniv10a.html)

阈值仍在 Session 3 固定，并检查每个类别的覆盖率，避免 Pinch 被大量拒绝、总体覆盖率却看起来合格。

### 5.7 P2：会话适配可以做，但先做“有界适配”，不是自由 TTA

第一版最安全的顺序：

1. **仅适配传感器 nuisance 参数**：中心、全局尺度、通道质量、环形偏移、重力/陀螺偏置、人体坐标；模型权重冻结。
2. 如果仍不够，在 60 秒有标签校准块上只更新类别 prototype、最后一层 bias 或一个低维仿射适配器；主干冻结，并限制参数变化范数。
3. 每次佩戴从原始冻结模型重新开始；适配前后都保存指标与参数，可一键回滚。
4. 无标签在线 TTA 首先只在 shadow mode 记录。Tent 一类方法通过最小化预测熵在线改变归一化参数，能处理某些分布偏移，但它依赖模型自己的预测；类别不平衡、Unknown/OOD 和错误伪标签会造成过度自信甚至塌缩。[Tent 原论文](https://openreview.net/pdf/4de0af9691a5dcc52de7de756676fded33d037ef.pdf)、[开放集 TTA 风险研究](https://arxiv.org/abs/2308.06879)

对本项目而言，60 秒有引导校准已经提供了比无标签 TTA 更可靠的证据，所以不应越过它直接做在线自训练。

## 6. 用实验把“采集问题”和“代码问题”真正拆开

下一轮不要只比较“同日 vs 跨日”，而应做以下受控矩阵。每个条件至少重复两次，所有分割以 trial 为单位。

| 实验 | 日期 | 是否重戴 | 放置是否受机械标记约束 | 目的 |
|---|---|---|---|---|
| A | 同日 | 否 | 同一佩戴 | 测分类器在近似同分布下的上限 |
| B | 同日 | 是 | 是 | 隔离重戴本身 |
| C | 跨日 | 是 | 是 | 在放置受控时测生理/环境日变化 |
| D | 跨日 | 是 | 刻意旋转 1 通道 | 验证 shift 校准和旋转增强 |
| E | 跨日 | 是 | 刻意小于 1 通道偏移 | 验证整数 roll 的残余限制 |

对每个条件分别运行以下消融：

- 无任何 session 校准；
- 只做 EMG 中心/尺度；
- 再加环形 shift；
- 再加 IMU 人体坐标；
- 再加跨 session 增强；
- 最后加受约束的校准头适配。

同时报告：

- D/H macro-F1、联合准确率和每类 F1；
- coverage、risk@90% coverage、ECE；
- 静息噪声、通道 SNR、shift margin、人体旋转残差；
- 每 session 的特征分布距离；
- onset-to-stable P50/P95；
- 丢包、插值和坏窗口比例。

这样才能回答：下降中多少可由佩戴规范挽回，多少由校准代码挽回，多少必须靠多 session 训练，多少是硬件不可观测。

## 7. 建议的实施优先级与停止条件

### 第一阶段：先让数据“可相信”（必须完成）

- 修正全部 2000→250 的真实语义；保存标称与实测率。
- 改造逐包/逐样本时间轴与 EMG–IMU 对齐掩码。
- 加入采集前质量闸门和校准残差。
- 固化佩戴标记、通道方向、松紧记录和动作标签。

**停止条件**：任何正式 session 都能生成质量报告；时间严格递增；缺包/插值可追溯；失败通道和失败校准不会静默进入训练。

### 第二阶段：让经典基线跨佩戴稳定（最高算法优先级）

- 做三种 EMG 尺度方案消融。
- 做多手势共识 shift + shift 置信度。
- 已实现按 session/trial 平衡训练，以及环形旋转、通道 dropout、幅值和 IMU 偏置
  增强；仍需在正式数据上做有/无这些改动的预注册消融。
- 使用新的完整 28 组合数据训练独立 D/H SVM 与 LDA。

**决策门**：如果 Session 3 的 D 或 H macro-F1 尚未达到 0.80，先看质量/校准消融，不进入更复杂网络；若经典基线接近目标且跨 session 混淆有稳定结构，再进入 TCN。

### 第三阶段：时序和拒识

- Open onset→hold 记忆；独立 P_arm/P_hand 状态机。
- qD/qH 温度校准、质量联合拒识、每类 risk–coverage。
- 测量真实端到端 P95 延迟，而不是只计算模型推理耗时。

### 第四阶段：受约束适配与神经模型

- 先试 prototype/末层小参数有标签适配；
- 再比较环形 CNN+TCN；
- 无监督 TTA 只做影子实验，达到预注册的跨 session 提升且无类别塌缩后才考虑上线。

### 最终 Session 4

冻结采集格式、校准算法、模型、阈值和状态机后才打开 Session 4。Session 4 前允许的 60 秒校准操作和可更新参数必须提前列入清单；结果不理想也不能回头改算法再重测。

## 8. 不建议现在做的事

- 不要求采集“绝对完美”，也不靠无限重录掩盖自然变异；质量合格即可，变异要进入训练。
- 不把 250 Hz 软件上采样成 1000/2000 Hz 后宣称获得更高频信息。
- 不重新加入已被旧数据否定的“总 MAV 阈值 = 手势类别”规则；它最多是阶段辅助。
- 不把 16 路或高密度外部数据空间插值成伪 8 路直接喂当前输入头。
- 不让 D/H 使用彼此标签共现捷径；完整组合矩阵和辅助头必须继续保留。
- 不在正式测试流上自由更新全部模型权重。
- 不把 A 当绝对肌力、M 当真实位移、C 当医学异常。

## 9. 最终判断

采集层和代码层都需要优化，但分工不同：

> **采集程序负责把偏移、质量和时间记录清楚；分类程序负责对仍然存在的偏移保持鲁棒；硬件边界决定哪些状态只能依赖时序记忆或输出 Unknown。**

如果只优化采集，系统会在真实重戴和状态变化时继续掉点；如果只优化分类，模型会在错误时间轴、坏接触和标签混杂上学习伪规律。结合当前硬件，最划算的投入顺序是：时间/质量可审计 → 60 秒校准 → 经典基线跨 session 增强 → 时序与拒识 → 小参数会话适配 → 最后才是更复杂网络和无监督 TTA。
