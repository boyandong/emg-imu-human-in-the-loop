# F9 document-exact primitive observations

The opt-in `DocumentQualityObservationsV3` implements the F9a–f observations without changing the historical F9 family or its saved public results. A strict `<` comparison is used for zero samples and flatline edges. The longest run is divided by the full window length. Robust amplitude uses raw source MAD in `1.4826·MAD + ε`; line and low-band ratios also use additive ε rather than flooring the measured denominator. These differences are covered by independent threshold-boundary, constant-source, and direct-Fourier known-signal tests.

ADC range, 50/60 Hz mains frequency, raw/pre-highpass status and circular channel order are explicit inputs. Missing metadata sets the corresponding availability flag to zero and leaves that observation at zero; target windows never set thresholds or reference statistics. Zero/flat tolerances come from explicit metadata or source windows; source windows also freeze activation medians/MADs, covariance and optional neighbor-correlation reference. The output is `8C+5` features: eight per-channel observation groups, one covariance distance and four availability flags.

This is an analytical formula implementation and an optional observation API. It is **not** a validated gesture predictor or a promoted F9 quality mask. Prior [Song and GRAB gate evidence](../new_bank_v2/F9_GRAB_GATE_REPORT.md) found many false rejects for the illustrative soft gate, while the strict structural gate found no natural classification errors. Hardware-fault ground truth and safe live routing remain unproved.
